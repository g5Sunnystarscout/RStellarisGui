# FIXTURE: the BROKEN event file. Every `geocentric_unga_main_option_effect = yes` call has been

# engine's close control selects, so this closes the window and immediately re-opens it.

########################################################################
# Geocentrism - UN General Assembly windows
#
# Six windows, six events, ONE window on screen at a time.
#
# The left sidebar of every window is the engine-filled event option list (the container
# named "option_list" that lives in the window's EVENT_DIPLO container, which the .gui places
# in the sidebar). Each committee entry is therefore an EVENT OPTION, not a button:
# choosing an option consumes the event it belongs to, so the window it was drawn in is
# dismissed and the event fired from that option's hidden_effect replaces it. That is what
# makes opening a panel dismiss the previous one instead of stacking another window.
#
# Evidence:
#   * No engine effect closes an event window. logs/script_documentation/effects.log lists
#     1056 effects; none matches close/window/dismiss/gui (only close_branch_office,
#     set_closed_borders, open_shroud_tab, force_show_diplomacy, force_show_espionage).
#   * An effectbuttonType inside a live window only fires its button_effect; the window stays.
#     That is what produced two stacked NATO windows.
#   * Vanilla switches sub-screens exactly this way: events/caravaneer_events.txt:498-532
#     (a cara.200 option whose hidden_effect fires cara.210) and it guards the entry point
#     against duplicates with `has_active_event` (common/scripted_triggers/
#     02_scripted_triggers_caravaneers.txt:9-19). Kasako's framework does the same:
#     events/FW_evts_CORE_panel.txt:276-380 (options) -> FW_efts_MODMENU.txt:141 (next event).
#   * `custom_gui` on an option chooses that option row's container; event level
#     `custom_gui_option` is only the default (Stellaris wiki, Event modding: "Can be
#     overwritten by custom_gui used in option's themselves").
#
# `diplomatic = yes` is required for `custom_gui` to be honoured. `force_open = yes` is kept as
# in the working state (vanilla uses it on 128 diplomatic events; nothing in the engine
# documentation ties it to window stacking, and removing it would risk the window not opening).
########################################################################
